# José Mercado · CV web

Currículum y presentación profesional de José Mercado, con foco en desarrollo de software, automatización e inteligencia artificial.

## Contenido

- Perfil, experiencia y proyectos.
- Áreas de aporte: desarrollo, automatización e IA y datos.
- Herramientas, formación e idiomas.
- Diseño adaptable a teléfonos y escritorio.
- Vista de impresión para guardar como PDF.

## Uso local

Abre `index.html` directamente en tu navegador. No requiere dependencias ni compilación.

Para usar un servidor local:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000`.

## Edición

Todo el contenido, los estilos y las interacciones están en `index.html`. Para actualizar el CV, edita ese archivo y recarga la página.

## PDF

Usa el botón **Guardar como PDF** y selecciona la opción para guardar como PDF en el diálogo de impresión del navegador.
