## Uso local

Abre `index.html` directamente en tu navegador. No requiere dependencias ni compilación.

También puedes servir la carpeta con:

```bash
python3 -m http.server 8000
```

Luego abre http://localhost:8000.

## Edición

El contenido, los estilos y las interacciones están en `index.html`. Los diplomas están en `certificados/`.

Los enlaces a los certificados son relativos, por lo que funcionan tanto en Sites como en GitHub Pages o en un servidor estático.
