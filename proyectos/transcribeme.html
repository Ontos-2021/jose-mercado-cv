Transcríbeme.cl

Recuperar acuerdos o apuntes de una grabación larga no debería exigir volver a escucharla entera.

Visitar Transcríbeme.cl ↗

01 / Necesidad

Encontrar lo importante

Una reunión, una entrevista o una clase pueden dejar un buen registro de audio, pero cuesta encontrar una decisión concreta o compartir lo que quedó pendiente.

02 / Mi aporte

De archivo a documento

Desarrollé una aplicación web para subir grabaciones, transcribirlas y organizarlas en un resumen descargable. Trabajé el flujo de producto y la implementación con Django y React, integrando modelos de IA para procesar el audio y el texto.

03 / Resultado

Beta pública

El producto permite cargar un audio, revisar el texto y descargar el resultado. Es útil para volver sobre un acuerdo, archivar apuntes o compartir un resumen sin reenviar toda la grabación.

Qué muestra la captura

Un ejemplo preparado para explicar el flujo, no material de un cliente ni del concierto de Bebop.
